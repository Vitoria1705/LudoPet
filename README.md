# 🐾 LudoPet

Sistema web desenvolvido para auxiliar na adoção responsável de animais, permitindo o cadastro de pets e o gerenciamento de processos de adoção.

## 🚀 Sobre o Projeto

O LudoPet foi criado como projeto acadêmico com o objetivo de conectar animais que precisam de um lar a pessoas interessadas em adotar.

## ✨ Funcionalidades

* Cadastro de animais
* Listagem de animais disponíveis
* Registro de adoções
* Atualização de informações
* Exclusão de registros
* Banco de dados integrado

## 🛠 Tecnologias Utilizadas

* Java
* Spring Boot
* Thymeleaf
* HTML
* CSS
* Bootstrap
* MySQL

## 📚 Conceitos Aplicados

* CRUD Completo
* Programação Orientada a Objetos
* MVC
* Banco de Dados Relacional
* Injeção de Dependência
* Polimorfismo

## 🎯 Objetivo

Desenvolver uma solução tecnológica para auxiliar o processo de adoção responsável de animais.
